# Instagram UI/UX Design

 Project Overview

This project is a UI/UX design of the Instagram mobile application.
The main aim of this project is to recreate the basic Instagram user interface
with simple, clean, and user-friendly screens.

 Objective

- To design an attractive Instagram-style interface.
- To understand the basic principles of UI/UX design.
- To create simple and easy-to-use navigation.
- To design important Instagram screens using Figma.

 Screens Designed

 1. Instagram Splash Screen
- Instagram logo
- Instagram branding
- "From Facebook" text

 2. Login Screen
- Instagram logo
- Phone number, email or username field
- Password field
- Login button
- Forgot login details option
- Login with Facebook option

3. Home Screen
- Instagram header
- Stories section
- Post section
- Like, comment and share icons
- Navigation bar
- Profile icon

 4. Profile Screen
- Profile picture
- Username
- Posts, Followers and Following
- Edit Profile button
- Share Profile button
- Add Highlight option
- Posts, Reels and Tagged tabs
- Bottom navigation bar

 5. Explore/Search Screen
- Search bar
- Image grid
- Different categories of posts
- Bottom navigation bar

Tools Used

- Figma
- UI/UX Design
- Wireframing
- Prototyping
- Visual Design

 Features

- Simple and clean interface
- Instagram-style navigation
- User-friendly layout
- Consistent icons and spacing
- Attractive visual design
- Easy screen-to-screen navigation

Design Elements

- Typography
- Icons
- Buttons
- Image cards
- Navigation bar
- Search bar
- Profile components
- Story highlights
   Conclusion

This project helped me understand the basic concepts of UI/UX design
and how to create a mobile application interface using Figma.
The design focuses on simplicity, consistency, and user-friendly navigation.
